# 지역사회봉사 최종보고서 점검

위덕대학교 지역사회봉사 수강생(1학년)이 최종보고서 PDF를 제출하기 전에 스스로 점검하는 웹앱입니다.

- 학생 화면: `index.html`. 전공·학번·이름으로 입장한 뒤 PDF를 올리면 항목별 「통과 / 보완 / 확인 중」을 보여 줍니다. 점수는 보이지 않습니다.
- 교수 화면: `admin.html`. 비밀번호로 들어가며, 학생별 오류 변화, 100점 환산 점수, 확인 필요 칸 판정, 오류 유형, 전공별 현황, 같은 파일·서명 의심 신호, 1365 발급번호, 표 파일 내려받기를 제공합니다.

## 개인정보와 파일

- PDF는 학생 기기의 브라우저 안에서만 읽습니다(pdf.js로 그리기, Tesseract.js로 글자 읽기). 파일은 어디에도 올리지 않습니다.
- 기록 서버(`Code.gs`, Google Apps Script + 구글 시트)에는 점검 시각, 전공, 학번, 이름, 오류 수, 점수, 항목별 판정, 파일 지문(SHA-256)만 저장합니다.

## 점검 기준 (규칙판 v1.0, 2026-10-22 교수님 확정)

| 영역 | 배점 | 내용 |
|---|---|---|
| 봉사시간 증빙 | 40 | 1365 확인서 첨부(15), 총 20시간 이상(20), 하루 8시간 이하(5). 1365·VMS·대학 확인서·헌혈증을 합산하고 헌혈은 장수와 관계없이 최대 4시간 |
| 기관 날인 | 20 | 신청서마다 대표자·담당자 서명·도장 (칸마다 5) |
| 빈칸 없음 | 25 | 표지·계획서·신청서·일지·결과 보고서의 칸 (칸마다 2) |
| 구성·일치 | 10 | 다섯 가지 문서(각 1.5), 표지 담당교수 「최현석」(2.5) |
| 작성 형식 | 5 | 양식 안내 문구 남김(3), 일지 차수 번호 겹침(2) |

필수 요건(1365 확인서, 20시간, 날인, 빈칸)이 하나라도 빠지면 학생 화면에 「보완」 도장이 찍힙니다. 자동 판정이 어려운 칸은 「확인 중」으로 두고 감점하지 않으며, 교수 화면에서 판정하면 점수가 다시 계산됩니다.

## 설치

1. 구글 시트를 하나 만들고 확장 프로그램 > Apps Script에 `Code.gs`를 붙여 넣습니다.
2. 프로젝트 설정 > 스크립트 속성에 `ADMIN_PW`(교수 화면 비밀번호)를 넣습니다.
3. 배포 > 새 배포 > 웹 앱(실행: 나, 액세스: 모든 사용자)으로 배포하고 주소를 `config.js`의 `API_URL`에 넣습니다.
4. GitHub Pages로 저장소 루트(main)를 게시합니다. pdf.js와 Tesseract.js는 jsDelivr에서 불러옵니다.

## 쓰는 라이브러리

pdf.js 4.10.38 (Apache-2.0), Tesseract.js 5 (Apache-2.0)와 한국어·영어 학습 자료(tessdata_best_int), Pretendard 글꼴(SIL OFL).
